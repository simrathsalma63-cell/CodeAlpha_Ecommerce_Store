# LumaStore — CodeAlpha Full Stack Task 1

A professional-looking full-stack e-commerce store built for the CodeAlpha Full Stack Development internship.

## Requirements covered

- Product listings
- Product details
- Shopping cart
- Order processing
- User registration/login
- MySQL database for products, users and orders
- HTML, CSS and JavaScript frontend
- Node.js + Express.js backend
- REST-style API endpoints

## Tech stack

Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express.js  
Database: MySQL  
Authentication: bcryptjs + JWT

## Setup

1. Install Node.js and MySQL.
2. Open MySQL Workbench.
3. Open `database.sql` and run the complete script.
4. Copy `.env.example` to `.env`.
5. Put your MySQL password in `.env`.
6. Open this project in VS Code.
7. Run:

```bash
npm install
npm start
```

8. Open `http://localhost:3000`.
